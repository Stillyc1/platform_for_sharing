## Установка

1. Убедитесь, что у вас установлен [Poetry](https://python-poetry.org/docs/#installation). Если нет, вы можете установить его, следуя официальной документации.
2. Клонируйте репозиторий:
    ```bash
    git clone https://github.com/stillyc1/platform_for_sharing.git
    ```
3. Перейдите в директорию проекта:
    ```bash
    cd platform_for_sharing
    ```
4. Установите зависимости:
    ```bash
    poetry install
    ```
5. Создайте Database postgresql и примените миграции:
    ```bash
    python manage.py migrate
    ```

## Использование

1. Наполните базу данных тестовыми значениями, для проверки функционала:
    а. Создайте пользователей:
    ```bash
    python manage.py create_users
    ```
    б. Наполните базу данными:
    ```bash
    python manage.py loaddata fixtures/add_objects.json
    ```
2. Чтобы запустить проект, используйте следующую команду:
    ```bash
    python manage.py runserver
    ```
   
    После запуска приложения вы сможете получить доступ к нему по адресу http://127.0.0.1:8000/.

## Тестирование

1. Для запуска тестов используйте следующую команду:
    ```bash
    python manage.py test
    ```
   
## Функциональность

### Пользовательский интерфейс
#### Главная страница
1. Регистрация пользователя
2. Вход и выход пользователя
3. Просмотр списка объявлений
4. Поиск объявлений по ключевым словам, фильтрация по состоянию и категории
5. CRUD объявлений, защищены permissions, только владелец может изменять и удалять объект
#### Создание объявления
1. Форма с автоматической установкой времени создания created_at и присваивание user = self.request.user
#### Мои объявления
1. Просмотр объектов Ad текущего пользователя
#### Мои обмены
1. Список объектов ExchangeProposal (заявки на обмен)
2. Возможность просмотра Detail объекта.
3. Возможность произвести обмен (изменений статуса и обмен объектами Ad между пользователями)

### API
1. Регистрация пользователя через UserCreateAPIView
2. Получение информации о пользователе через UserRetrieveAPIView
3. Аутентификация через LoginUserView и LogoutUserView
4. CRUD объектов Ad (С автоматической установкой времени и текущего пользователя в атрибут - user)
5. Эндпоинт об обмене товарами ExchangeProposal
6. Фильтрация объектов Ad и ExchangeProposal
